# Achievement System

C# / .NET 8 기반의 게임 업적 시스템 예제입니다.

## 주요 기능

- 행동 기록을 기반으로 여러 업적의 진행도 갱신
- 조건 유형 및 대상 ID에 따른 조건 매칭
- Add / Max 방식의 진행도 누적
- 업적 상태 전이 및 완료 조건 검사
- 일일 / 주간 업적 초기화
- xUnit 기반 단위 테스트

## 설계 방향

### 진행도 처리

행동 기록 하나를 여러 업적 스펙에 반영합니다.
조건에 일치하는 경우에만 업적 상태를 생성하며,
진행도가 실제로 변경된 경우에만 완료 여부를 검사합니다.

### 상태 관리

NotStarted, InProgress, Completable, Claimed 상태를 구분합니다.
보상 수령 이후에는 진행도가 다시 누적되지 않도록 처리합니다.

### 주기 초기화

일일 / 주간 업적은 마지막 초기화 날짜를 기준으로
현재 주기에 맞춰 진행 상태를 초기화합니다.
영구 업적은 초기화 대상에서 제외합니다.

### 운영 환경 고려 사항

이 예제는 핵심 도메인 로직을 보여주기 위한 샘플이며,
DB 저장, 트랜잭션, 동시 요청 제어 및 보상 지급은 구현 범위에서 제외했습니다.

실제 서비스에서는 진행도 변경과 상태 변경의 영속성,
중복 행동 기록 처리, 보상 중복 지급 방지 등을 별도로 고려해야 합니다.

## 실행

.NET 8 SDK가 설치된 환경에서 실행합니다.

dotnet test AchievementSystem.sln
